## Important limitations
As of this research date the official docs list `deepseek-flash` and `deepseek-v4-pro` for hosted inference. Search/fetch and other application APIs are remote services; saving their descriptions does not preserve their backends.

## Offline documentation workflow
On a computer, save each page as HTML/PDF, note capture date and URL, and put it into a versioned Drive folder. Respect site terms and avoid bulk crawling without permission. Recheck pricing and request schemas before deploying production integrations. Keep API credentials in a secret manager, never in archived examples.
